# /// Next Gen Apparel — website

Static site (HTML/CSS/vanilla JS, no build dependencies).

- `index.html`, `shop.html`, `collections.html`, `about.html`, `contact.html`, `checkout.html` — the built pages (open directly or serve the folder).
- `src/<page>.src.html` + `src/partials/*.html` — source; run `python3 build.py` to regenerate every page. `<!-- @page shop -->` in a shell marks that nav item (`data-nav="shop"`) as the current page.
- Home extras (`src/partials/home-sections.html`, `css/home.css`, `js/home.js`): crossed caution tapes (brand + store perks), Most Wanted chart (top 8 in-stock from `js/products.js`, hover/focus swaps the preview), Index strip of skewed category panels (live counts), Drop 08 hang tag with countdown (date in `data-countdown`), Access Pass newsletter (client-side only). Shop also accepts `?stock=pre-order`.
- Shop page: `css|js/shop-hero.*` (banner + category tabs), `css|js/shop-listing.*` (filters, grid, pagination), `js/products.js` (catalog of 260 products — generated by `python3 tools/gen_products.py`, which also updates the filter counts in `src/partials/shop-listing.html`; run `build.py` after), `css/shop-band.css`.
- Contact: `src/partials/contact-page.html`, `css|js/contact-page.*` — form validates locally (no data is sent); `?type=general|orders|returns|partnerships|press` preselects the inquiry type. Reuses the shop bottom band.
- Checkout: `src/partials/checkout.html`, `css|js/checkout.*` — reads the bag (NGCart), promo `NEXTGEN10` = 10% off, standard shipping free over $150, cash on delivery only (no card fields; preview store, no payment taken). Placing an order saves it via `js/orders.js` (`window.NGOrders`, localStorage `nga-orders`) and shows the confirmation at `checkout.html?order=NGA-xxxxxx`.
- Order tracking lives on the Contact page (`#track`): `contact.html?order=…&email=…#track`; the status timeline is derived from order age (no carrier feed). Sample order: NGA-100248 / demo@nextgenapparel.ph.
- Collections / About: `src/partials/<page>.html`, `css/<page>.css`, `js/<page>.js`; their banners reuse the shop banner classes from `css/shop-hero.css`. Tabs and sidebar talk via `shop:category` / `shop:category-sync` events on `document`; `?category=` and `?sort=newest|popular` URLs work.
- Header (all pages): search submits to `shop.html?q=`; `js/cart.js` + `css/cart.css` provide the bag drawer (`window.NGCart`, `cart:add` event, saved in localStorage `nga-cart`, checkout at `checkout.html`) and the account "coming soon" dialog. Shop: `?product=<id>` opens the quick view.
- `css/base.css` — design tokens (colors, fonts, motion) shared by every section; `css/{header,hero,categories,contact}.css` — one file per section.
- `js/main.js` — scroll reveal; `js/{header,hero,categories,contact}.js` — per-section behavior (sticky header, menu/search overlays, hero carousel, footer arrow draw-in).
- `assets/img/` — images (copied from `streetwear-assets/`).
- `shot.sh <out.png> [w] [h] [page.html]` — headless Chrome screenshot (note: Chrome won't lay out narrower than ~500px headless).

Local preview: `python3 -m http.server 5173` then open http://localhost:5173.
